# Keyboard and mouse

Initial PS2 button mapping; gameplay actions will be verified in-game.

| Input | PS2 control |
| --- | --- |
| WASD / arrows | Left stick and D-pad |
| Space / Z | Cross — jump / confirm |
| E / X / right mouse | Circle — Force / special action |
| Left mouse / J | Square — attack |
| Q / Tab | Triangle — switch character |
| Enter / Esc / I | Start — pause |
| 1 / R | L1 / R1 |
| C / V | L2 / R2 |
| Backspace | Select |
| Alt+Enter | Fullscreen |

The first click or key press enables audio if autoplay is blocked. A connected
controller is supported by the runtime. Player 2 and co-op are unverified.
